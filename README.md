# Folder Marker

An [Obsidian](https://obsidian.md) plugin that adds a small colored mark to the left of folder names in the file explorer, like section tabs in OneNote.

## Features

- Colored chip on each folder, with automatic colors derived from one base color.
- Optional mark next to note names: icon, bullet or underscore.
- Optional auto reveal of the open note in the file explorer.
- Optional auto close of folders you are no longer working in.

## Settings

Go to **Settings → Folder Marker** to set the first folder color, the note mark, and the auto reveal and auto close options.

## Installation

### From the community plugins list

1. Open **Settings → Community plugins** and select **Browse**.
2. Search for **Folder Marker**, then select **Install** and **Enable**.

### Manual

1. Download `main.js`, `manifest.json` and `styles.css` from the latest release.
2. Copy them to `<Vault>/.obsidian/plugins/folder-marker/`.
3. Reload Obsidian and enable the plugin in **Settings → Community plugins**.

## Privacy

The plugin works fully offline. It makes no network requests and collects no data.
